### Project Documentation
For Software:
Project Documentation
Overview

A fictional, AI-powered "personality generator" web app. Users upload a photo, video, or audio clip (or pick a pre-made demo), and the app generates a fictional personality, mood, and imagined quote for that object/subject — purely for entertainment.

Problem Statement

There's no real problem being solved — the project is intentionally built as a lighthearted, "useless" project for fun/entertainment rather than utility.

Solution

An AI-driven web app that takes any uploaded media and generates a playful, fictional character profile (name, personality traits, and a quirky quote) for it, using generative AI to interpret the upload.

Features
Drag-and-drop upload for photos, videos, and audio
Instant demo mode with pre-built character cards (no upload needed)
AI-generated personality traits and quotes per subject
Rotating ticker of example generated results
Privacy note: no uploaded files are stored after the session
Fully bilingual UI (Malayalam + English)
Disclaimer

Explicitly stated on the site: this is fictional AI-generated entertainment, not a real psychological assessment, especially when used on photos of real people.

Tech Stack

See Technical Details section above (React, TypeScript, Tailwind, Lovable, AI API).

Future Scope
Add more demo characters/categories
Support sharing generated personalities on social media
Add sound/voice output for generated personalities
Expand language support beyond Malayalam/English

# Diagrams
*Upload/Select – User uploads a photo, video, or audio file (or taps a demo card like "Bananettan" or "Meow Meenakshi") to start.

*AI Analysis – The backend sends the input to an AI model, which generates a fictional personality profile (strengths, weaknesses, insecurities, flex) plus a "red flag" compatibility score.

*Backstory Generation – The AI expands this into a full "unnecessary life story" — backstory, hidden talent, biggest fear, life goal, and relationship status.

*Interactive Chat – The generated character becomes chattable ("Talk to Kappu Kuttappan"), letting users ask preset or custom questions and get in-character AI replies.

*Meme Export – A meme generator auto-captions an image using the character's persona (with tone options like Savage/Cool/Emotional, even in Malayali), which users can download or regenerate.
